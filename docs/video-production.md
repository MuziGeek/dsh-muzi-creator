# 跨平台视频制作

工作台通过本地工程引用和成片文件连接制作环节，不限定录制或剪辑软件。Windows、macOS、Linux 的路径与目录打开分别适配；实际运行仍取决于宿主、外部工具和依赖是否可用，不代表三种系统的整套桌面端均已验收。

## 绑定工程与素材目录

打开「内容 → 视频制作」，输入已有工程文件或目录的绝对路径，或通过「选择目录」选取目录，再点击「保存绑定」。可以保存包含中文和空格的路径。新的引用只记录在插件数据中，不移动、复制或修改原始工程。

「打开所在目录」打开工程文件的父目录或绑定目录本身，不执行所绑定的文件。路径已被移动或删除时，更新绑定后重试。「解除绑定」只清除引用，不删除工程、素材或视频。

旧 `studioPath` 记录继续可读；显式改绑或解绑才更新该条记录，不批量重写历史。Screen Studio 的专属打开仍仅供 macOS 上的可用安装使用。

## 等待成片

使用自己的工具完成录制、剪辑和预览，将 MP4/MOV 导出到当前内容目录。没有绑定工程或未安装 Screen Studio，也可以点击「等待成片」。工作台在文件稳定落盘后识别产物，再继续字幕与封面。

已有成片时无需重新等待。「停止等待」只取消当前内容的检测，不停止录制/剪辑软件，不删除导出文件。超时后检查导出目录和工具状态，再手动重试。

## 可选能力

- 字幕与封面按实际 Skill、Python 环境和凭据检查；仅存在一个目录不代表可运行。
- 上游字幕初始化脚本仍是 `setup.sh`。Windows 需要可用的 Git Bash/Bash，按上游说明初始化；插件不自动安装或改写第三方 Skill。
- Screen Studio 和 `screen-studio-editor` 为 macOS 专属适配，缺少它们不阻断通用工程引用和成片等待。
- 本次不包含自动剪切、时间线编辑、跨平台录屏引擎或新增编解码格式。
- 发布与同步继续遵循已有能力验收和逐次审批。

Agent 可通过 `mz_update_content` 的 `productionProjectPath` 保存路径，传 `null` 解除绑定；`mz_open_production_project_folder` 打开目录，`mz_wait_export` 等待成片。
