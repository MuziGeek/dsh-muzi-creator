# Local production-project references

A content item can reference an existing local project file or directory independently of its recording or editing software. Opening the reference resolves and opens only a directory; the reference never becomes a program or shell command.

Legacy Screen Studio bindings remain readable. Explicit rebinding or unlinking changes only that item's reference metadata, including suppression of legacy filesystem discovery when necessary. Loading historical records does not migrate project files or rewrite reports.

Export waiting observes the content directory independently of project binding and software capabilities. Cancellation stops only the owned watcher; a superseded wait cannot overwrite the result of a newer wait.

Screen Studio remains a macOS-specific adapter. Capability checks and operating-system path support do not imply end-to-end acceptance of third-party tools or DSH Desktop on every platform.
