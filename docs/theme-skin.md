# 工作台内置外观

木子工作台自带固定外观、34 枚图标和本地字体。安装插件即可使用，不需要皮肤中心、额外皮肤目录或手动选择皮肤。浅色、深色和跟随系统使用 DSH 原有设置。SSH、技能中心、任务看板均为可选功能，不是工作台的外观依赖。

## 样式与资源

src/client/appearance 保存主题、组件、宿主兼容与入口规则。工作台样式按拆分前实际安装包还原；视觉基准摘要记录在 visual-baseline.json。字体包括 Nunito 拉丁 500／700／900 和 Noto Sans SC 简体中文 400／500／700，附带文件摘要与 OFL 许可证。终端、代码保持宿主等宽字体。

外观样式与资源随客户端打包，插件激活时挂载，停用时移除标记、样式与字体声明。不会修改持久化主题值。木子卡片保持原有圆角，市场卡片单独使用 8px；矩形遮罩、防溢出、深色弹窗和键盘操作继续生效。

## 第三方入口

按钮按操作含义使用背景色：普通操作保留奶油色，文字与链接按钮默认透明；删除、移除等危险操作使用柔和红底，最终确认使用砖红实底。悬停与按下保持同一色系，深色模式有对应背景；禁用和处理中不响应悬停变色。导航选中、卡片和市场遮罩继续由各自的规则控制。

只适配木子侧栏中带插件标识、入口语义、名称且符合已验证图文结构的按钮。保留节点、名称、顺序和事件；已有木子图标按插件映射使用，未知入口展开时保留空图标槽，折叠时使用通用 SVG 和名称提示。未知结构保持原样，避免影响搜索和折叠按钮。

第三方页面继承支持的宿主变量；不能保证内部自定义组件完全一致。兼容登记以 Desktop 2.0.5 为基线。结构升级需复验，不匹配中文文案或生成的哈希类名。

## 换肤管理器与本地迁移

固定木子外观不与其他换肤管理器同时启用。公共安装包不自动停用其他插件，也不携带当前电脑的配置。使用全家桶的当前环境可单独停用 web-ui-skin-center；不要停用整个 dsh-web-all。保留旧皮肤目录、选择记录和安装备份以便回退。

停用木子后宿主侧栏空白属于已有侧栏装配问题；样式清理成功不代表侧栏装配已修复。本次不改变业务数据或功能启用状态。

## 构建验证

pnpm build:appearance 校验图标、字体及许可证，生成私有图片导入映射。pnpm build 将资源内嵌到客户端，不访问皮肤中心接口。字体和图标说明见 [工作台图标](iconography.md)。
