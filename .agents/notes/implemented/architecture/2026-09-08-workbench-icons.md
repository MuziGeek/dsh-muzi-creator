# Workbench feature icons

Generated Animal Island PNGs belong to the plugin client and are embedded through the existing asset loader. A semantic WorkbenchIcon name selects one asset; controls keep their accessible labels and event handlers.

The six navigation entries share their icon meaning with central feature headings and related actions. Platform identities, the Muzi avatar, directional controls and text-first knowledge cards retain their existing roles. The settings trigger uses the host's existing content slot and releases its registration on plugin disposal; it does not replace the host button or settings dialog.

The placement table and asset provenance live in docs/iconography.md and src/client/assets/workbench-icons/manifest.json.
