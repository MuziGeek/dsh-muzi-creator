# MZ names and existing data

Plugin-owned tool and remote identifiers use MZ names. Version 0.2.0 does not register aliases for the previous identifiers. Host, client, prompts, external-action classification and collection scripts must use the same vocabulary; existing muzi_creator tools retain their names.

External Skill names, executable paths and environment variables belong to their providers. Attribution and recorded historical content are preserved. Naming checks allow these exact exceptions and reject unclassified remnants.

An explicit dataDir determines storage. Automatic selection preserves a sole legacy directory and otherwise selects the MZ default; two existing candidate directories require explicit configuration. Selection does not move, merge or rewrite stored records.
