# 工作台图标

功能图标由 oil-icon 生成，配色参考 Muzi Creator 的 Animal Island 浅色与深色主题。32 枚透明 PNG 保存在 `src/client/assets/workbench-icons/`，`manifest.json` 记录来源和文件摘要；`WorkbenchIcon` 通过静态导入将图片内联到客户端包，运行时不依赖外部图片地址或本地生成目录。

| 新会话、设置入口 | 会话气泡、设置齿轮 | 28 px |

图标使用留有安全边距的 128 px 原图，在浅色和深色主题下保持原色。文字、无障碍名称和状态标签继续表达功能；图片为空替代文本并对辅助技术隐藏，不增加焦点，也不截获点击。知识条目保持文字优先，不增加装饰图标。

平台标志保留微信、小红书、抖音和 B 站的身份含义。普通取消、弹窗关闭及小型下拉箭头保留原有符号或文字；头像与品牌标志不使用功能图标替换。

设置按钮通过已有 `settings.trigger` 插槽替换内容，宿主继续控制按钮、设置弹窗及其交互。注册在插件卸载时释放。官方会话工具栏、消息工具渲染和设置分区的图标由宿主所有，不通过隐藏 SVG 或修改宿主 DOM 替换。

工作区标题不使用装饰图标。搜索、视图和添加保留宿主原版 SVG 图标按钮，不附加文字标签；原有无障碍名称、提示和事件保持不变。内容概览中的“查看制作”和“管理发布”只保留文字。

## 操作图标

新增的 16 枚操作图标默认以 24 px 图标配合原有文字展示。刷新与重试共用循环箭头；清除搜索、移除记录和停止操作使用不同图形。复制、外部链接、目录选择和账号核验保留原有事件、提示与确认流程。加载状态由按钮组件管理，不单独旋转图片。

| 图标名称 | 对应位置 |
| --- | --- |
| `refresh` | 刷新、重新读取与重试 |
| `view-options` | 列表视图选项 |
| `copy` | 复制灵感报告 |
| `clear` | 清除搜索 |
| `back` | 返回概览、返回修改 |
| `sidebar-open / sidebar-close` | 展开列表、侧栏收起与展开提示 |
| `fit-view` | 知识星图适应视图 |
| `folder-open` | 选择目录、打开项目与制作目录 |
| `external-link` | 打开平台、授权页面和外部资料 |
| `add` | 新建连接、添加仓库和既有创建表单 |
| `remove` | 移除工作台记录、仓库或账号 |
| `stop` | 停止研究、停止等待 |
| `connect / disconnect` | 连接或解除账号、仓库及制作项目绑定 |
| `verify` | 登录核验和连接检查 |

收起的侧栏保留品牌头像，悬停或键盘聚焦时显示展开图标。图片是装饰内容，辅助技术读取原有按钮或链接名称。侧栏记录为移除按钮预留空间，避免图标与标题重叠。现有入口是否显示继续由业务状态决定，不因新增素材恢复已移除的入口。
