# 灵感搜索

灵感页用于手动查找资料并保留可回查的研究结果。它与「热点」页分开：热点页读取 AIHOT 已聚合的事件；灵感页根据本次主题和时间范围发起搜索。

## 搜索一个主题

1. 打开「灵感」，默认选中「主题搜索」。
2. 输入具体主题，点击「搜索」或按回车。主题不能为空。
3. 等待进度结束，按「总结 → 主要发现 → 分歧与创作角度 → 来源」阅读结果，正文默认完整展开。

默认使用中英文公开网络资料、标准深度和中文总结。需要宿主已经配置可用模型及公开网络搜索能力，无需配置字幕、封面或发布 Skill。

灵感研究员保留当前会话预设提供的 `web_search` 和 `web_fetch`，搜索使用宿主选择的提供方，包括已配置的 ModSearch。研究工具名单按该 Agent 的作用域生成；普通会话的工具不受影响，Shell、文件写入、子代理委托和发布仍由研究角色策略禁止。更新插件后重启宿主，再手动重新搜索；失败的历史报告不会自动重跑。

## 查找历史

灵感列表顶部带放大镜图标的「搜索」按钮用于筛选历史。点击后展开输入框并聚焦，输入关键词筛选已有记录；按 Escape 或点击「清除」会收起输入框、恢复完整列表并将焦点返回按钮。「刷新」重新读取历史记录。侧栏不提供独立的研究入口；研究表单位于中央工作台，从报告返回概览后可重新填写，只有提交表单才开始研究。

## 获取指定期限内的热点

切换「获取热点」，选择时间范围后点击「获取」。主题可留空，留空时获取综合热点；填写主题则缩小研究范围。

| 时间范围 | 计算方式 |
| --- | --- |
| 近 24 小时（默认） | 从本次点击向前 24 小时 |
| 近 7 天 | 从本次点击向前 7 天 |
| 近 30 天 | 从本次点击向前 30 天 |
| 自定义日期 | 按 Asia/Shanghai 的自然日计算，包含起止两天 |

自定义起止日期必须有效，开始日期不能晚于结束日期，结束日期不能在未来。每次运行固定保存实际起止时间；重新获取相对期限会重新计算窗口，不沿用上一次报告的结束时间。

## 判断结果是否可用

- **总结**直接给出主要结论。原文中连续编号的主题标签单独显示为小标题，长内容在句号或分号处断段；没有明确编号结构时保留普通段落，正文与复制结果不被改写。
- **主要发现**逐条编号展示观点和案例；热点报告说明事件和关注原因，引用位于正文下一行。
- **分歧与未知**显示报告记录的来源支持、分歧或不确定状态，**创作角度**单独列出可用切入点。
- **来源**提供原文链接和发布时间，显示编号与正文引用一致。编号只用于当前页面定位，复制结果仍保留原始报告及来源标识。

限期热点不能使用日期未知、无效或范围外的来源作为窗口内依据。来源不足时展示部分结果及原因；没有可靠来源时显示空结果，不强行生成素材。报告不编造全网排名或热度数字；时间校验也不代表已独立核验原网页事实。

## 复制、重搜与后续创作

「复制结果」包含来源链接；「重新搜索」创建新的运行记录。历史统一保留在侧栏，旧报告继续可读。

报告操作直接显示专用会话、已配置 Obsidian 的文档定位和「转为内容」，无需展开「更多」。转为内容会开启普通会话并讨论三个方向，不直接创建正式内容、写入 Atlas 或发布。后续创作操作按原有确认流程执行。

## 停止与恢复

运行时可以停止，切换页面不会中止任务。失败、停止或宿主重启中断后不自动重试，可以手动重新搜索；旧报告的正文和校验值不会因新版本而改写。

每日自动研究已停用。插件加载时暂停旧计划、清除后续调度并取消尚未执行的自动队列，不在重启后补跑；计划历史和报告仍保留。

研究报告保存在配置的 Creator Studio 根目录下 `00-inbox/inspirations`。插件通过结构化报告写入并保留 SHA-256 校验；灵感专用 Agent 无权执行 Shell、改动项目、写入 Atlas、创建正式内容或执行发布。

历史卡片支持删除，确认后仅从工作台移除；报告文件和 Agent 会话保留。单次报告的删除不影响同一主题的其他报告；删除最后一张报告卡片时，该主题也从历史列表隐藏。运行中的研究需先停止。

删除确认使用工作台现有的 Animal Island 弹窗，显示卡片标题和本地文件保留说明。默认聚焦“取消”，支持 Esc 关闭并返回删除按钮；提交期间禁止重复删除和关闭，失败时在弹窗内显示错误并允许重试。
