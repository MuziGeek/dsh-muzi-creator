# Muzi Creator Animal Island surface brief

## Approved composition

`mocks/composition-c-compact-island-console.png` is the approved implementation reference. It preserves the current three-column product structure while keeping controls compact enough for the desktop host and the 1024 px layout. Composition A is the visual richness ceiling. Composition B is rejected because its notebook treatment consumes too much working space.

## Required visible ingredients

- Product name: Muzi Creator.
- Primary navigation: 会话、热点、内容、知识、项目.
- Content workspace: 个人工作台.
- Inspector tabs: 概览、母内容、视频稿、公众号、小红书、博客、证据、视频制作.
- Conversation remains visible in desktop split mode and keeps the title 探索未至之境.
- Publishing remains preparation-only and must not imply automatic publication.
- Source provenance, safety gates, status, empty, loading, disabled, error, hover, and keyboard focus states remain discoverable.

## Visual system

- Warm cream and parchment surfaces, cocoa text, muted leaf and mint accents, and soft yellow focus.
- One rounded sans-serif family with restrained size steps.
- 12-18 px component radii; pills only for compact controls and tags.
- Dimensional treatment only for primary or destructive actions.
- Animal Island components are the control vocabulary; project CSS provides layout and host integration.
- No gradients, glass decoration, cold gray, pure black, fake metrics, character art, or decorative dashboard cards.

## Responsive behavior

- Keep the current three-column hierarchy on wide desktop layouts.
- Compact or collapse the plugin sidebar before reducing content legibility.
- Preserve the existing full-width inspector behavior on narrow screens.
- Dropdowns and dialogs must escape scroll clipping and remain keyboard accessible.
