# 内容工作台使用说明

灵感页的主题搜索、限期热点、结果与历史操作见 [灵感搜索](inspiration.md)。

## 隔离 UI Lab

Lab 用于本地检查界面组件和响应式布局，不执行发布、同步或归档。先运行 `pnpm build`，再用 `pnpm lab:setup` 创建项目内 `.lab/` fixture、隔离用户目录和供系统选择器使用的 `Desktop` / `Documents` / `Downloads`，随后运行 `pnpm lab:config` 写入隔离 Web profile。使用 `pnpm lab:start -- --cli <已构建 DSH CLI 路径> --port 51873` 启动 Web；源码版 DSH 应传 `apps/cli/lib/bin.js`，不能直接传 TypeScript 入口。不提供 CLI 时脚本会明确提示，不能把未启动当作通过。

Desktop 2.0.4 使用独立的 `.lab/desktop-home` 与 `.lab/desktop-user-data`：脚本写入并在每次启动前严格核对 `<user-data>/profile-selection/state.json` 的 `{ "version": 2, "active": "web" }`、`desktop-market/state.json` 的显式 `disabled` 状态，以及 `<desktop-home>/settings.yaml` 的 `dsh-desktop.mode: compatibility`。旧版 `version: 1` 状态会被 2.0.4 判为无效并回退到 `desktop` Profile，因此 Lab 会在启动前直接拒绝旧格式。`lab:desktop -- --desktop <路径>` 仅接受版本资源严格匹配 2.0.4 且当前没有同路径进程的已安装 Desktop 普通可执行文件，传入独立 `--user-data-dir`，并将 `DSH_HOME`、`HOME`、`USERPROFILE`、应用数据、遥测、凭据与外部能力隔离；任一版本、运行实例、profile、源码链接、可写路径、选择状态或 `lib/` 构建产物偏离时拒绝启动，不会接管个人 Desktop 或 `~/.dsh`。Desktop 缺失时验收为 `UNVERIFIED`。

源码联调继续使用受控的源码链接 Web profile。为本地成品安装验收做准备时，只能把已有 `.tgz` 放进 `.lab/packages/`，再运行 `pnpm lab:desktop -- --prepare-tgz .lab/packages/<包名>.tgz`；该命令只核对隔离条件和归档位置，不下载、不安装、不启动 Desktop。详见 [DESIGN.md](../DESIGN.md)。

## 独立个人模式

需要在隔离 Desktop 中读取真实 Creator、Atlas 和 Trellis 数据时，先在 `scripts/lab-personal-config.mjs` 中核对 `PERSONAL_WINDOWS_PATHS` 与本机目录，再运行 `pnpm lab:personal:config` 和 `pnpm lab:personal:desktop -- --desktop "<DSH Desktop 可执行文件路径>"`。该模式使用 `.lab/personal/dsh-home`、`.lab/personal/user-data` 和 `.lab/personal/data`，不会读取或覆盖正式 `~/.dsh` 与 `~/.dsh-mz-creator`。真实 Windows 用户目录仅用于系统路径发现；内容、Creator、Atlas、项目和 Obsidian 路径来自已核对的个人配置。

个人模式仍清空凭据并禁用外部动作和发布目标，但它读取的业务目录是真实目录。界面中的创建、整理、归档等操作可能修改真实文件；隔离验收只检查读取、导航、路径展示和独立工作区注册，不执行这些写操作。

DeepSeek Harness 打开后，左侧可在「会话 / 热点 / 灵感 / 内容 / 知识 / 项目」之间切换。会话显示完整的 DSH Agent；其余入口默认打开对应概览；再次点击当前入口也返回概览，点击具体卡片才进入详情。一条内容对应 `~/Movies/视频项目/` 里的一个文件夹，名字是 `日期_可读标题`。

菜单区默认只显示「会话、热点、灵感、内容」四行，向下滚动依次查看知识、项目和第三方插件入口；右侧细滚动条提示还有菜单。菜单与下方卡片列表分别滚动，品牌栏和底部设置保持可见。键盘焦点进入隐藏菜单项时会将该项滚入菜单可见区域。切换功能保留当前菜单滚动位置；刷新页面或重新展开侧栏后从菜单顶部显示，已恢复的功能选择不受影响。

热点概览按「今日必看 / 值得浏览 / 其余动态」展示本次聚合返回的全部条目，各组显示条数，可向下滚动浏览并点击任意条目打开详情。「全部热点」统计当前可读条目，不代表上游全站事件总数。

功能列表顶部标题与操作按钮同排并垂直居中，不显示数量统计。会话的“工作区”标题不带装饰图标，搜索、视图和添加保留原版小图标按钮及提示。内容栏保留搜索和视图选项；知识栏显示「知识」标题与搜索，两栏都不提供新增按钮。知识概览与详情仍可从导航和列表进入。灵感栏带放大镜图标的「搜索」用于展开历史筛选，研究表单位于中央工作台；正文统计、分组数量和运行状态提示继续显示。

## 对话工具能不能走完整条片子

不能。片子的正文在影片目录的文件夹里，对话用系统自带的列文件、读文件、写文件去看和改。`mz_*` 只做文件做不到的事：按约定建文件夹、绑工程、等导出、生成或烧录字幕、生成封面、标记发布、同步已发布数据。它们不负责录屏、剪时间线、从剪辑工具导出成片、写四平台发布包、把视频上传到创作者后台，也不负责公众号成稿。

人仍然要自己完成这几件：

- 使用自己的录制或剪辑工具，预览后导出 MP4/MOV 到内容目录
- 在字幕预览里确认专有名词后再烧录
- 看封面标题和错别字，决定要不要再生成
- 在各平台点最终「发表」

可选的 Screen Studio 剪辑适配和四平台上传分别由 `screen-studio-editor`、`video-publisher` 负责。这两项没有做成 Harness 工具。公众号图文走 `oil-video-article`。

所以对话可以推动一条片子往前走，不能代替录制、导出和最终发表。

## 界面怎么用

Muzi Creator 加载后会把 DSH Web 内容统一为 Animal Island 视觉：侧栏、会话背景、消息与工具卡片、输入区、设置、菜单、弹层和右侧详情共享暖色浅色/深色主题。主题跟随 DSH 的“浅色 / 深色 / 跟随系统”选择，插件不会改写这个偏好。Windows 标题栏、文件选择器和系统安全提示仍使用系统样式。

左侧列表显示每条片子的阶段和时间。已经在任一视频平台发出去的，显示「已发布」；成片、字幕、封面都齐但还没发出去的，显示「待发布」。

点开热点、内容、知识或项目条目后，详情直接显示在中央工作台，不再打开可拖动的 Overlay。刷新页面保留最后一次有效详情；点击功能入口或“返回概览”只清除对应功能的选择，键盘切换入口同样打开概览。切回“会话”后，原来的当前会话、草稿、队列和流式状态保持不变；后台 Agent 不会因为查看工作台而停止。会话入口在存在待处理交互时优先显示“待处理 n”，否则显示“运行中 n”。

内容详情提供概览、母内容、视频稿、公众号、小红书、博客、证据和视频制作页签。分类栏与正文上下拼接，概览顶部显示小封面、标题、阶段和更新时间。视频制作、稿件、发布在宽屏中从左至右并排，标题分别使用灰绿、暖杏和青绿底色；空间不足时制作摘要通栏或三个模块依次堆叠。稿件列表可直接进入对应正文，并提示来源是否更新。制作摘要只显示当前阶段和下一步，详细步骤在“视频制作”查看。“查看制作”和“管理发布”使用纯文字按钮。发布列表按平台显示已有发布记录、时间及作品链接，博客单独标明文章发布；当前任务单独显示，平台草稿、已排程、待确认提交和已发布不会混为一谈。提交结果未知时需要核查平台结果。

“管理发布”默认收起，点击在三个模块下方通栏展开账号、模式、排程、原创确认、准备、最终提交和数据同步；账号能力验收默认继续折叠。收起不清空输入、不取消任务；切换另一条内容时恢复收起。阻塞及待确认提醒始终可见，点击可展开并定位对应平台。播放、点赞、评论及记录来源在管理区域查看，原有发布审批条件保持有效。

窗口小于 880px 时，只有点选具体条目才会折叠侧栏；切换入口、查看概览或刷新不会折叠。详情顶部的“展开列表”会恢复到对应条目。

右边输入 `@`，可以选择「当前详情」或搜以前的片子。发出去的是那一期的文件夹路径，封面、脚本、字幕都在里面，按 [files.md](files.md) 自己去列、去读。`/current content` 同样只带当前打开那条的文件夹路径。

设置在 Harness 的设置 → 插件 → 个人内容工作台。「项目来源」集中配置本地项目目录与 GitHub 仓库，操作与保存方式见 [项目来源](github-projects.md)。这里也可以配置影片目录、`enabledPlatforms`、脚本规则（人设）和凭据。影片目录默认是 `~/Movies/视频项目`。`enabledPlatforms` 有小红书、抖音、B 站、视频号四个开关，默认全部启用；AI 发布和数据同步只处理启用的平台，全部关闭时不执行这两项操作。脚本规则是写 `script.md` 时 AI 必须遵循的语气、结构和禁忌，也可以直接在对话里让 AI 记录，AI 会用 `mz_script_rules` 存到同一个地方。字幕转录使用百炼 `DASHSCOPE_API_KEY`，封面使用 ZenMux `ZENMUX_API_KEY`，两者和视觉识别共用官方凭据；页面只显示已配置或未配置，不会把 Key 读回来。

宿主皮肤固定针对 DSH Desktop 2.0.4 / 内置 Harness 0.1.2-alpha.1。升级 Desktop 前先在隔离 Lab 重新检查会话、输入、审批、设置、菜单和弹层；固定版本选择器不匹配时应停止验收，而不是继续扩大 CSS 覆盖。

首次使用推荐选 Harness 的 `standard` 或 `code` Agent preset，再直接说「检查并配置内容工作台」。内置 `creator-workbench` Skill 会让 AI 先调用 `mz_creator_setup` 检查环境。AI 能从系统发现的目录和能力不再逐项追问；任何写入都会先预览，用户确认后才应用。`minimal` preset 没有 Skill 和文件工具，不适合首次引导、自动整理目录或修改正文。

装完不知道能做什么时，直接问「这个插件怎么用」。AI 会调用 `mz_creator_guide`，拿到带当前能力状态的完整指引后告诉你：哪些环节现在就能用，哪些还缺依赖。Windows 页面准备和数据回收依赖本机 Chrome 与插件固定的 Patchright；找不到 Chrome 时会明确降级，片库、脚本、字幕、封面不受影响。

候选影片目录不存在时，先让 AI 展示准备创建的完整路径；确认后创建目录，再重新预览配置并确认应用。`mz_creator_setup` 只接受已经存在的目录，不会暗中创建文件夹。

## 对话里怎么读片子

先列出影片目录（默认 `~/Movies/视频项目`），再打开 `日期_标题` 那个文件夹。脚本是 `script.md`，选题是 `topic.md`，文章在 `公众号文章/`。完整约定见 [files.md](files.md)。

插件工具只做这些：

| 工具 | 作用 |
| --- | --- |
| `mz_creator_guide` | 自举指引：返回完整工作流和当前能力状态，用户问「这个插件怎么用」时先调它 |
| `mz_script_rules` | 读或写脚本规则（人设）；写改 script.md 前先读 |
| `mz_creator_setup` | 只读检查环境，或先预览、确认后保存目录和启用平台 |
| `mz_create_content` | 按今天的日期新建文件夹 |
| `mz_update_content` | 标记待录制、绑定工程、改某一平台的发布标记 |
| `mz_open_production_project_folder` | 打开通用工程所在目录，不执行工程文件 |
| `mz_open_studio` | macOS 上打开已绑定的 Screen Studio 工程（可选适配） |
| `mz_wait_export` | 等到文件夹里出现稳定的 MP4 / MOV |
| `mz_generate_subtitles` | 转录、自动校对、排版；立刻返回；完成后打开预览，出现 `subtitle-transcript.json`，不烧录 |
| `mz_open_subtitle_preview` | 在浏览器打开字幕预览编辑器 |
| `mz_burn_subtitles` | 用户预览确认后再烧进成片；立刻返回；完成后出现 `*_subtitled.mp4` |
| `mz_generate_cover` | 一键生成 3:4 / 4:3 / 16:9 封面，立刻返回；完成后出现对应 png |
| `mz_sync_publish` | 用独立 Chrome 账号目录翻完启用平台的已发布列表，按标题或已存 id 写回播放 / 赞 / 评 |
| `mz_creator_profile` | 读或改 `enabledPlatforms`，即 AI 发布和数据同步使用的平台列表 |
| `mz_organize_library` | 预览或把文件夹改成 `日期_可读标题`，默认只预览 |

长任务都是先启动，再看文件夹里有没有产物，不要把一次启动当成已经完成。

`muzi.creator/2` 项目通过 `muzi_creator_prepare_publish_flow`、`muzi_creator_publish_flow`、`muzi_creator_resume_publish_flow` 和 `muzi_creator_commit_publish_flow` 与界面共享发布流程。`muzi_creator_video_publish_capabilities` 只读查询能力证据，`muzi_creator_video_publish_status` 查看底层任务；`muzi_creator_sync_video_metrics` 仍需单独验证数据读取能力和获得同步授权。`muzi_creator_begin_video_acceptance`、`muzi_creator_finalize_video_acceptance` 仅用于数据读取验证，发布能力验证由当前内容的协调流程负责。

## 账号管理

在内容模块概览页点击「账号管理」，再点击「连接账号」，选择平台并打开浏览器。手动完成平台登录后，工作台自动核验创作者身份；只有登录有效且平台账号 ID 明确时，账号才添加成功。没有内容项目也可管理账号，设置页保留同一入口。内容详情页只选择已连接账号。

主列表只显示最近验证成功的账号，包括已验证但主动停用的账号；每行通过「打开平台」或「管理」操作。旧账号、失效登录和未完成的移除放在默认收起的「账号连接问题」栏中，不显示为已连接账号。展开后直接重新连接、重新验证、启用或移除；只有移除操作需要确认弹窗。没有已验证账号时，页面显示连接引导。

连接过程中可重新检查、重新打开浏览器或取消。默认连接有效期为 10 分钟，界面每 2 秒检查一次；自动检查与手动检查不会同时运行。暂时关闭弹窗后可通过「继续连接」恢复，取消则结束当前连接。关闭浏览器不会被轮询自动重开。过期或失败后请重新开始连接。浏览器资料保存在本机独立账号目录；重新登录使用原目录。

小红书从创作者首页连接，身份来自首页个人资料中的昵称和账号 ID。若旧连接停在上传页，请点击浏览器中的「首页」再检查。上传页只有昵称时，准备和提交的身份检查使用单独的首页标签，不覆盖已填写的上传页面。

账号连接与上传发布权限分开。连接不会启用 `externalActionsEnabled`，也不授予发布能力。账号页显示最近核验状态；准备和提交前会重新检查真实登录与身份，失效时暂停该目标，完成重新登录后可继续。停用账号保留资料和历史记录。

「管理 → 移除账号」需要确认，会解除绑定并清除该账号专用浏览器的本机登录资料，内容和发布历史保留。账号正在执行操作时需等待操作结束。清理失败的账号移入「账号连接问题」，保持不可发布并提供重试移除；移除最后一个账号后仍可新建连接。移除后新建连接使用新资料目录，原发布准备需重新执行。

问题账号的重新连接进度显示在原账号行下，折叠期间自动检查继续；有进行中的问题连接时，重进页面会恢复对应进度并展开。连接期间不能同时启动另一条连接。验证成功并读取账号库后，账号移回主列表。登录后仍未验证时，查看账号行内或新增连接弹窗中的具体提示。账号程序在本机账号配置目录保存有限大小的阶段诊断记录，供核对程序路径、连接检查和保存结果；它不保存页面正文、密码、Cookie 或平台账号身份。不要将界面预览中的示例账号视为真实连接结果。

## 发布内容

点击内容卡片进入详情，打开发布面板，选择平台、账号和模式。候选只包含已启用、身份及登录已核验的账号；没有可用账号时需先回到概览连接。每个平台选择一个账号，可一次准备多个平台；默认「仅准备」，定时使用中国标准时间。账号失效、停用或移除后清空对应选择，不自动换号，原准备结果不能继续提交。点击「开始准备」授权当前所选目标的浏览器检查、素材上传和页面填写。上传和发布需要先在插件配置中开启外部操作。

工作台按目标依次检查登录并准备内容，首次使用所需的能力验证融入本次任务，不需要进入独立验收区，也不会额外发布测试作品。失败目标不会阻止其他目标准备，可在处理提示的问题后单独继续。任务进度持久保存，重开详情可恢复。

准备完成后，核对平台、账号、标题、素材、模式和定时时间，统一确认本次就绪目标的最终提交。每个平台的提交授权独立且只使用一次。仅准备停在可检查的页面，不能据此认定平台草稿已保存。修改内容或目标配置后需重新准备；提交结果不明时先核实平台结果，不自动重试。

Agent 可通过 `muzi_creator_accounts` 查询账号，通过连接工具打开或恢复账号登录，通过 `muzi_creator_prepare_publish_flow`、`muzi_creator_publish_flow`、`muzi_creator_resume_publish_flow` 与 `muzi_creator_commit_publish_flow` 使用同一流程。准备请求不包含最终发布授权，Agent 必须在展示准备结果并获得最终确认后才能提交。

## 新做一条片子

先在右边说这一期讲什么。可以让对话新建内容，例如：「今天做一期 DeepSeek Harness 安装上手，建文件夹，把选题写进笔记。」

对应工具是 `mz_create_content`。选题写进这一期的 `topic.md`，脚本写进 `script.md`，也可以之后在中间「脚本」页自己改。

录制与剪辑使用自己的工具即可。在「内容 → 视频制作」中填写已有工程文件或目录的绝对路径，保存绑定；也可选择目录。打开操作只打开目录，不执行工程文件；解除绑定只清除引用。旧 Screen Studio 工程继续可读，macOS 专属打开操作仍然保留。

预览满意后，在剪辑工具中导出 MP4/MOV，目标为这一期的内容目录。可以不绑定工程直接点击「等待成片」；「停止等待」只取消检测，不关闭编辑器或删除视频。已存在成片时直接继续字幕与封面。macOS 用户可额外使用 `screen-studio-editor` 处理 Screen Studio 工程；本插件不新增自动剪辑引擎。详见 [跨平台视频流程](video-production.md)。

导出开始后说：「等这条的成片落盘，落盘后生成字幕和封面。」`mz_wait_export` 会等到文件大小稳定。成片到了再用 `mz_generate_subtitles` 出字幕稿并打开预览；用户确认后再 `mz_burn_subtitles`。封面用 `mz_generate_cover`，调用前先按 oil-cover 提炼主标题传入 `title`。生成后要在对话里核对标题和错别字，不对就再说一次生成。

首次 clone `oil-subtitle` 后必须运行 `bash ~/.agents/skills/oil-subtitle/setup.sh`，否则字幕工作流不会就绪。不要在预览前烧录。`mz_burn_subtitles` 不会覆盖已经带字幕的成片文件名习惯，产物文件名里带 `_subtitled`。

成片、字幕、封面齐了，阶段会变成「待发布」。四平台上传使用 `video-publisher`，但只处理启用的平台。每个平台可独立选“仅准备 / 立即发布 / 定时发布”；页面准备完成后，立即或定时动作还要逐个平台确认。定时使用平台原生排程，不依赖电脑到点运行；平台不支持或拒绝时间时直接阻塞，不会改成立即发布。「同步播放数据」从创作者后台读取播放、赞和评论，90 秒内重复同步默认使用缓存，也可强制刷新。

公众号不是第五个视频平台。需要图文时，另外喊 `oil-video-article`。工作台只显示文件夹里有没有 `公众号文章/`。

## 把一条没做完的旧片子收尾

先打开那条，或 `@` 它，或者说出文件夹路径，例如 `~/Movies/视频项目/2026-08-13_DeepSeek Harness 安装上手`。让对话列出这个文件夹，看缺的是工程、成片、字幕、封面、文章还是发布标记。

常见说法：

- 「这条还缺什么，缺的就做。」
- 「把这个本地工程路径绑定到当前内容，打开它所在的目录。」
- 「生成字幕，完了打开预览。」
- 「字幕我看过了，烧进去。」
- 「再生成一版封面。」
- 「把脚本改成下面这一版，写进 script.md。」
- 「小红书标成已发布。」
- 「同步四个平台的播放和点赞。」

列表阶段会跟着变。已经在平台发出去的，左侧会显示「已发布」，不再显示「待发布」。

## 同步之后数据在哪里

旧片库的 `mz_sync_publish` 仍把播放、赞、评论和链接写在 `~/.dsh-mz-creator/overlay.json`。`muzi.creator/2` 项目改用追加式 `creator-metrics.jsonl` 保留每次快照，项目文件只在发现新的远端身份或发布事实时更新。匹配严格按远端 ID、规范化 URL、唯一精确标题；同名候选返回歧义，不自动绑定。四个平台都需要先在各自的独立 Chrome 账号目录登录。

## 设置和目录

第一次用先让 AI 检查环境，再确认影片目录。字幕、封面、Screen Studio、Chrome 与平台验收都是可选能力，缺少时不会影响片库和脚本管理。字幕和封面没有 Key 时，对应按钮会提示去设置里填写。有成片后，内容详情里可以生成字幕稿并打开预览，确认后再烧录；封面也可以在内容详情里生成，不用再走对话。

文件夹名被连字符弄乱时，可以说：「预览整理影片目录。」确认后再让它真正重命名。`mz_organize_library` 默认只预览，不会删文件。

数据目录以有效 `dataDir` 为准；旧目录保留，新安装默认使用 MZ 目录。详见[升级与命名说明](mz-naming.md)。

### 删除灵感与内容卡片

点击卡片上的「删除」并确认，只从工作台移除该记录；本地目录、稿件、报告文件及会话保留。删除后刷新或重启不会重新显示卡片。灵感研究运行中需先停止；删除一份报告不影响同主题的其他报告。若删除失败，卡片保留并显示原因，可刷新后重试。灵感报告的会话、Obsidian、转为内容和历史报告入口默认直接显示。

灵感报告底部的复制、重新搜索、会话、Obsidian 和内容转换使用统一按钮并按顺序换行。其他历史报告在按钮下方选择。顶部返回、刷新与桌面面板控件分开排列，窄面板中标题与操作分行显示。

在「设置 → 皮肤」选择“木子·暖岛”可统一宿主与木子工作台外观；切换其他皮肤时木子页面同步变化。皮肤不改变 SSH、技能中心等模块的启用状态。安装和回退见 [主题皮肤](theme-skin.md)。
