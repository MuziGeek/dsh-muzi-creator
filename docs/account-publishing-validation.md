# 账号连接与发布流程验证

验证日期：2026-09-09。实现位于 MZ 创作插件及 Creator Studio 的 `video-publisher` 运行时。下列记录区分插件回归、外部运行时夹具和真实平台验收；未执行真实平台上传、发布或定时提交。

## 已执行

- 插件：10 个相关测试文件、76 项通过，覆盖账号桥接、移除 RPC、概览入口、详情过滤、读取失败、选择失效、旧准备结果撤销、移除确认和清理失败后的重新读取。补充已验证停用账号保留、独立问题入口、检查互斥、取消失败与迟到响应、保存后回传失败恢复，以及能力查询失败时仍返回已保存账号。
- 运行时：5 个相关测试文件、58 项通过，覆盖四平台身份夹具、多标签页、普通提示文字误判、可见验证码、取消后迟到响应、重复身份、并发占用、目录链接拒绝、清理失败重试及移除最后一个账号。补充指定配置路径写入与重新读取、连接阶段诊断关联和诊断不包含账号身份。浏览器在轮询检查与连接之间退出时，程序也不会重新启动浏览器。真实子进程夹具验证了先核对进程归属再关闭、清理资料，以及拒绝不属于该资料目录的进程。基线的插件 15 项、运行时 14 项与以上测试均不能证明真实平台连接成功。
- `pnpm typecheck`、`pnpm build` 及两处仓库的 `git diff --check` 通过。
- 普通 Node 24.15.0 与实际 DSH Desktop Electron 43.3.0 可执行程序均通过四平台子进程连接、跨进程持久化、移除及最后账号空状态冒烟测试；身份和资料目录全部使用隔离夹具。
- Electron 隔离夹具验证了请求与回传诊断的关联、连接保存，以及程序与配置路径一致；夹具结果不证明正式 Desktop 的真实连接成功。
- 用户在 Chrome 完成小红书登录后，只读核对真实创作者首页的当前账号区域、昵称和唯一稳定账号 ID。发布页只提供昵称，首页 `.home-card-wrapper .personal .base` 提供小红书账号；据此调整识别规则。没有读取或导出 Cookie、令牌或日常浏览器登录资料，也没有将真实账号信息写入夹具。
- 本地组件预览使用内存示例接口检查 1440×900 桌面和 390×844 窄屏布局、空项目入口、详情候选、带账号名称的移除确认，以及最后账号移除后的禁用准备空状态。窄屏无横向溢出，临时窗口尺寸已恢复；预览不登记或删除真实账号。
- 本轮新版账号页检查桌面、390 像素及 630 像素布局，验证主列表隐藏旧账号、停用后保留已验证账号、管理弹窗状态同步、独立问题弹窗及连接异常提示。预览操作明确提示其为合成数据，不能用于证明真实连接。

登录验收需要用户在各自的专用浏览器完成扫码、密码或验证码操作。普通 Chrome 页面的登录不能代替专用账号资料的连接。身份不唯一或页面存在安全验证时，系统保持待处理。验收不执行真实上传、发布或定时提交；仅准备也不等于平台草稿已保存。

## 本机交付



Desktop 的本机页面在自动化浏览器中返回 `ERR_BLOCKED_BY_CLIENT`，原生 Desktop 操作工具不可用。实际加载及专用浏览器登录验收需要用户正常退出并重启 Desktop，再从「内容概览 → 账号管理」重新登录；不强制结束用户会话。`externalActionsEnabled` 保持关闭。

## 账号页宽度调整

账号页在工作台横向 Flex 容器中撑满剩余空间，提供独立纵向滚动；桌面内边距为 24 px，窄工作台为 16 px。标题、列表和问题入口对齐，昵称与状态归组，验证时间及操作靠右，账号行根据容器宽度切换为纵向排列。

使用实际工作台的外层结构和样式进行合成数据验证：994 px 工作台中列表宽 946 px，左右内边距各 24 px；1440 px 桌面、390 px 窄屏及宽窗口中的 520 px 工作台均无横向溢出。验证单账号、空状态、管理弹窗，以及 24 个长昵称账号的页面内纵向滚动。相关 3 个测试文件共 25 项通过，类型检查、构建、布局扫描和修改文件差异检查通过。此次只修改布局，不重复运行未改动的账号运行程序测试。


## 问题账号折叠栏

「账号连接问题」默认收起，问题账号复用已连接账号的纸色列表，恢复操作和连接进度均在账号行内。折叠不暂停检查，恢复到进行中的问题连接时自动展开；移除及重试移除保留确认弹窗。顶部新账号连接与已验证账号的管理入口保持原交互。

4 个相关测试文件共 39 项通过，覆盖折叠状态、按钮资格、行内重连、折叠期间轮询、成功移入主列表、失败后重试、跨账号重连互斥、取消失败和迟到响应、连接恢复、移除确认与发布选择失效。类型检查、构建及布局扫描通过。真实工作台外层结构的合成预览检查 1200 px 桌面、390 px 窄屏，以及宽窗口中的 520 px 工作台；问题栏和进度区无横向溢出，连接时无对话框。合成成功后主列表从 2 个增加至 3 个，问题列表从 3 个减少至 2 个；这些结果不代表真实平台登录验收。

## 账号管理弹窗

账号状态与启停按钮同排，重新验证和重新连接等宽排列；移除账号与关闭位于分隔后的底部。按钮点击区域至少 44 px，窄于 380 px 时恢复操作纵向排列，长账号名允许换行。移除仍进入独立确认，不在管理弹窗中直接删除账号。

2026-09-09 的局部检查通过账号管理及操作图标 18 项测试、类型检查与构建；620 px 和 320 px 的组件预览确认布局及停用后的禁用状态。正式插件安装文件与已验证的弹窗函数、样式一致，安装保留其他界面调整、依赖和配置；运行中的 Desktop 仍需重启后验收。安装包、备份路径和逐文件哈希仅保存在本机安装记录中。
